### Hi, I'm Sama

I graduated from the University of Birmingham in 2026 with a First in Computer Science. I like work that sits between the backend and the person using the screen: making text easier to read for people with dyslexia, turning NASA data into something you can click through, or giving a small shop a website that feels made for it.

- Building **[LexiLift](https://github.com/Sayrz1/Final-Year-Project--Lexilift)**, a browser extension that rewrites web pages so they're easier to read for people with dyslexia
- Interested in NLP, accessibility, HCI and fast, light systems
- Ask me about Angular, Spring/JHipster, Three.js or evolutionary algorithms
